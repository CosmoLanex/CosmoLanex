# Contributing

Thanks for taking a look. A quick note on how this repository works before opening anything.

This repository is Cosmo Lanex's personal GitHub profile and the source for the NUKRAX brand presence on GitHub. It isn't an open-source project, and code contributions or pull requests aren't currently accepted here.

## Found an issue?

If something in this README is broken, outdated, or unclear — a dead link, a formatting bug, a typo — feel free to open an issue. That kind of feedback is genuinely welcome.

## Interested in working together?

For project inquiries, collaborations, or questions about NUKRAX services, reach out directly rather than through a pull request:

- **Email:** [contact@nukrax.com](mailto:contact@nukrax.com)
- **Website:** [nukrax.com](https://nukrax.com)

## Other NUKRAX repositories

Some individual repositories under this account may carry their own license and contribution terms. Check that repository's own `README.md` and `LICENSE` before assuming these guidelines apply there.
